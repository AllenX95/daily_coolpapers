LLM Profile

参数说明

Provider
决定请求格式。OpenAI Compatible 会请求 {base_url}/chat/completions；Anthropic 会请求 {base_url}/messages。
Base URL
API 根地址，不包含具体接口路径。示例：https://api.openai.com/v1、https://api.anthropic.com/v1。
Model
模型 ID。摘要评估可用成本较低模型，全文阅读建议选择长上下文模型。
Context Window Tokens
只用于本地估算，防止整篇 Markdown 超过模型上下文；不会自动分块。
Prompt 模型绑定
每个 Prompt 可单独绑定模型。绑定后优先使用绑定模型；未绑定时使用默认摘要模型或默认全文模型。
